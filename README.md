# Pirovino Treffen 2027 – Supabase-Version

Samstag, 12. Juni 2027 · Mörsburg, Winterthur

Diese Version verwendet Supabase statt SQLite.

## Supabase-Tabelle

Im Supabase SQL Editor ausführen:

```sql
create table public.responses (
  id bigint generated by default as identity primary key,
  name text not null,
  attending boolean not null,
  guests jsonb not null default '[]'::jsonb,
  email text not null,
  created_at timestamptz not null default now()
);

alter table public.responses enable row level security;

create policy "allow anonymous inserts"
on public.responses for insert
to anon
with check (
  char_length(name) > 0
  and char_length(email) > 0
);

create policy "allow anonymous select"
on public.responses for select
to anon
using (false);
```

Hinweis: Der Server verwendet die Supabase-Umgebungsvariable `SUPABASE_KEY`. Für Render bitte den dort vorgesehenen Server-Key verwenden, nicht einen privaten Schlüssel im Frontend veröffentlichen.

## Render Environment Variables

Im Render Web Service unter Environment:

- `SUPABASE_URL` = deine Supabase Project URL
- `SUPABASE_KEY` = dein Supabase Server-Key
- `ADMIN_KEY` = ein eigenes geheimes Passwort für `/admin`

Build Command: `npm install`
Start Command: `npm start`
